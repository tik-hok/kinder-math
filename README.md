# 🌰 松果數學樂園

幼兒園大班的數學遊戲，由小松鼠「松松」陪孩子一起玩。

**馬上玩：** https://tik-hok.github.io/kinder-math/

## 5 種玩法
- 🔢 **數數看**：數數看有幾個。可以點一點，一個一個數。
- ⚖️ **比多少**：哪一邊比較多（或比較少）？
- ➕ **加加看**：用圖片做加法；大松果模式也有減法。
- 🧩 **找規律**：AB、AAB、ABC 的排列，下一個是誰？
- 🚂 **數字火車**：火車少了哪一號？

## 兩種難度
- 🌱 小松果：數到 10，加到 5
- 🌳 大松果：數到 20，加減到 10

## 讓孩子覺得有趣、有成就感
- 可以切換「中文（台灣）」和「English (US)」：題目、按鈕和語音都會跟著換，中文用台灣國語語音，英文用美式英文語音
- 題目都用語音念出來，還不太會認字也能玩
- 答對有音效、彩帶和稱讚；答錯不扣分，錯兩次會給提示
- 每關 5 題，至少拿 2 顆星，每過一關得到一張動物貼紙（共 20 張）
- 進度存在這台裝置的瀏覽器裡

只有一個 `index.html` 檔案，不需要安裝任何東西。
